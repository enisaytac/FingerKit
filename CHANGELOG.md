# Changelog

## [0.1.0] - 2026-10-30

First public release.

- Trackpad gestures: multi-finger swipes, clicks, taps, double taps, TipTap, edge swipes and corner taps, globally or per app
- Hyper Key: Caps Lock as ⌘⌥⌃⇧, open apps, snap windows, move windows by holding Caps Lock
- Clipboard history with a picker next to the pointer; items marked private by password managers are skipped
- App-specific shortcuts: remap keys or trigger menu items in one app
- Radial menu from the bottom-left corner of the trackpad: brightness, volume, Bluetooth, AirDrop, most used apps and the front app's shortcuts
- Community favorites on every page: popular settings with an animated preview, added in one click; new users start with an empty setup
- "Check for updates" button opens the releases page in your browser (FingerKit itself never connects to the internet)
- Interface in 8 languages: English, Turkish, German, Spanish, French, Portuguese (Brazil), Simplified Chinese, Japanese
- Universal app: Apple Silicon and Intel
